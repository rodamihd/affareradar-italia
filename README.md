# AffareRadar Italia

Sito statico pubblico per AffareRadar Italia.

## Pubblicazione su GitHub Pages

1. Crea un repository pubblico chiamato `affareradar-italia`.
2. Carica nella root del repository i file `index.html`, `.nojekyll` e `README.md`.
3. Vai su Settings > Pages.
4. In "Build and deployment" scegli "Deploy from a branch".
5. Branch: `main`, cartella: `/ (root)`.
6. Salva e attendi la generazione dell'URL pubblico.
